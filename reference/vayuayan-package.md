# vayuayan: Comprehensive Air Quality Data Analysis for India

Fetch and analyze air quality data from multiple sources including CPCB
(Central Pollution Control Board) India and WUSTL ACAG satellite PM2.5
data. Provides functions for historical and real-time AQI monitoring,
geospatial station location services, and satellite PM2.5 data
processing.
